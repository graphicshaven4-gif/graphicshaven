# Graphics Haven — Creative Design Studio

A full-stack web application for Graphics Haven Creative Studio featuring a dynamic single-page portfolio, interactive project inquiry form powered by Web3Forms, Cloudinary media storage, and a protected Admin Dashboard backed by Express and MongoDB Atlas.

## Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Backend**: Node.js, Express, MongoDB Atlas (Mongoose), Cloudinary, JWT Authentication
- **Forms**: Web3Forms direct email dispatch
- **Hosting**: Vercel (Fluid Compute Serverless Functions + SPA)

## Administrative Access
- **Portal**: `/admin`
- **Dashboard**: `/admin/dashboard`
